# 订单工作台模块

此目录是土田朵本机订单工作台的源码副本，只包含合成样例 `sample_orders.csv`，不含真实数据库、导出报表或登录资料。该模块默认只监听 `127.0.0.1:8765`；OBA 桌面端的“订单工作台”页使用原生 `WebContentsView` 显示它，其余直播功能仍由 OBA 原模块提供。

隔离开发时指定独立端口和数据目录，并给 OBA 桌面端设置相同端口：

```bash
TUTIANDUO_DATA_DIR=/绝对路径/隔离数据 TUTIANDUO_PORT=18765 python3 -B workbench/app.py
TUTIANDUO_PORT=18765 npm run dev
```

第一条命令从仓库根目录执行。工作台打开即显示订单页，不再要求首次设置或登录；旧数据库及其中的设置记录不会被清空。服务仅绑定 `127.0.0.1`，校验请求 Host；所有写入表单同时校验同源 Origin、浏览器请求来源和进程内随机表单令牌，以阻止第三方网页向本机工作台提交导入。OBA 打开的抖店浏览器仍由用户自行登录；下载的候选 ZIP/CSV 留在 OBA 用户数据目录 `OrderReports/`，不会自动导入。导入前仍需核对报表 ID、店铺、筛选范围、生成/下载时间、必需字段、行数和拒绝数。

订单后台浏览器目前提供**官方页面手动登录及下载监听**；自动筛选、发起导出、等待报表生成、完整性核验和一键导入仍未实现或实测。直播中控登录不代表订单后台已接通。不要把本模块当作正式抖店 API 授权。

导入时只要有一行校验失败（含重复子订单），整批报表拒绝发布，保留上次成功快照。待发货矩阵按店铺指向已发布批次，取消订单或整批没有待发货时不会回显旧批次；只有上游已确认完整空集合时才能显式发布空快照。这只能防止已识别的坏行覆盖；对于表头正确但漏页、漏时间段或仅含部分订单的报表，仍需在发布前取得并核对平台总行数、完整范围与店铺身份。当前不支持把浏览器下载候选文件自动当作完整待发货快照。

OBA 的抖音小店直播中控登录成功会通知订单同步协调器，并按 OBA 账号显示“待核验”状态；断开或重新登录会取消旧代次，店铺 ID 未核实前不得发布订单。订单页的真实只读读取、完整报表导出和分页终止条件尚无已验收适配器，因此该通知只表示可以开始订单权限核验，**不表示登录即完成同步**。订单适配器需要先提供核实的数字店铺 ID 与完整报表证据，再调用原子发布；不能把直播昵称当作店铺 ID。

用户可直接从左侧“订单履约 → 连接店铺后台”进入独立连接页，不必先连接直播中控。该页按 OBA 账号分别打开非无头抖店浏览器，并给出打开中、待登录、检测到登录但订单权限待核验、失败及断开状态；用户在抖店官方页面自行登录。登录检测只采用已知用户名标记，未检测到不等于证明未登录；不能把订单后台打开或登录状态当成同步成功。当前会话只在 OBA 运行期间保存，不持久化订单浏览器登录秘密。账号间浏览器和候选下载目录隔离。
